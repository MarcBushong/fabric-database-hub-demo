# Hyper-V guest build

Builds and configures the T2 guest `arcsql01` on the host ([ADR 0003](../../docs/adr/0003-t2-host-size-security-type-bootstrap.md), [ADR 0004](../../docs/adr/0004-guest-imds-isolation.md), [ADR 0006](../../docs/adr/0006-sql-editions-and-licensing.md)). `Invoke-HostBootstrap.ps1` dot-sources these files; they run as SYSTEM on Windows PowerShell 5.1. In the default `JumpstartImage` mode (since 2026-11-05) the guest isn't built: it's Arc Jumpstart's prebuilt SQL Server Standard image, which `GuestJumpstart.ps1` downloads and prepares; the other modes, `ProductKey` and `Developer`, build it from the evaluation ISO, as the retired `PaygWizard` mode did.

| File | Purpose |
|---|---|
| `GuestJumpstart.ps1` | The default `JumpstartImage` mode: the image's download (a HEAD request, then a resumable download that hashes while it writes, verified against the blob's Content-MD5 and length, fail closed, and compared with the pin in `config/versions.json`: a newer image is a **Warning** once it passes the checks), the published default credential (read at run time from Arc Jumpstart's `ArcServersLogonScript.ps1` at a pinned commit, checked by SHA-256, kept only in memory, never stored), the first boot over PowerShell Direct while the network adapter isn't connected (a random password, the name `arcsql01` and UTC, SQL Server's server name, `BUILTIN\Administrators` as sysadmin, SQL logins disabled, the sample database dropped, Integration Services and Launchpad disabled and IS uninstalled, `C:\Jumpstart` deleted, any Arc identity reset; then the adapter connected), and the image checks before Arc onboarding (Standard, SQL Server 2022, the default instance, sysadmin). |
| `GuestVhdx.ps1` | Builds the Generation 2 VHDX (GPT: EFI, MSR, Windows) with DISM from the evaluation ISO's Datacenter (Desktop Experience) image, adds the unattend file, and makes it bootable with `bcdboot`. A `.built` marker makes the step idempotent. A build that was stopped part way (a restart, the task's time limit, or a loader taking over) can leave the ISO and the VHDX attached; the next build detaches them first (2026-11-06). |
| `unattend.template.xml` | Computer name, time zone, locale, OOBE settings, and the Administrator password token. It holds no secret; the host fills the tokens in memory and writes the result only inside the mounted VHDX. |
| `GuestVm.ps1` | Generates the guest password (DPAPI, LocalMachine), creates the VM (static memory, Secure Boot with the Microsoft Windows template, automatic start, `ShutDown` stop action, no checkpoints; in `JumpstartImage` mode on the downloaded image, with its network adapter not connected until the first boot is done), and waits for PowerShell Direct. |
| `GuestHardening.ps1` | Inside the guest: static address, DNS through the host, outbound firewall blocks for `169.254.169.254` and `168.63.129.16`, and deletion of the unattend files. On the host: deny port ACLs for the same addresses, which the guest can't remove. |
| `GuestSql.ps1` | Copies files into the guest, mounts the SQL Server ISO, runs unattended setup with the switches from Microsoft Learn (`/PID` only in `ProductKey` mode), detects the instance and edition, and runs the `database/` scripts in the guest with Windows authentication. For a guest built in `PaygWizard` mode (retired 2026-11-09), it also installed the WebView2 runtime before the wizard; in every mode it removes the sign-in data left on the VM, verifies that none remains, and turns IE Enhanced Security Configuration back on. |
| `GuestSetup.ps1` | Phase 28's `PaygWizard` guided stop, retired on 2026-11-09, so only its cleanup still runs, for what an earlier guided stop left (the guard before every pass) ([ADR 0006](../../docs/adr/0006-sql-editions-and-licensing.md#amendment-one-command-one-guided-stop-phase-28-2026-10-29), [ADR 0009](../../docs/adr/0009-secrets-handling.md#phase-28-amendment-the-guests-one-automatic-sign-in-and-the-portal-password-reset-2026-10-29)): the SQL Server setup configuration file (`UIMODE` Normal, every page documented parameters can pre-fill, no secret), the guest's launcher and logon task (`C:\DbHubDemo\setup`), the host's logon task that opens Virtual Machine Connection, setup's Azure sign-in prepared before anyone is asked (the WebView2 runtime checked, IE Enhanced Security Configuration off for administrators, Microsoft's sign-in hosts as Trusted sites for the guest's Administrator; live finding, 2026-10-30) and undone in the cleanup from a snapshot, the guest's one automatic sign-in (the password only as the LSA `DefaultPassword` secret, `AutoLogonCount` 1) and its cleanup (sign-out, `AutoAdminLogon` 0, the secret and the Winlogon values deleted, the password rotated, checked), and the check of what the person installed, with the documented fix for a wrong install. |
| `Copy-GuestCredential.ps1` | Operator helper for interactive access to the guest, for example the missing-index fix (and, until 2026-11-09, the `PaygWizard` step by hand): copies the guest password to the clipboard and never prints it. `-Clear` empties the clipboard. The host bootstrap copies it to `C:\ProgramData\DbHubDemo\` in every mode. |
| `GuestWorkload.ps1` | The host's `WorkloadRunner` step (Phase 13, [ADR 0010](../../docs/adr/0010-workload-generator-technology.md#phase-13-delivery-and-hosting-as-built-2026-10-20)): waits (`WaitingForGuestSql`) until the guest's SQL Server runs, then copies the runner, the .NET runtime, and the wrapper into the guest, runs the runner's setup for T2, and registers the guest's `DbHubDemo-Workload` task. |

In the build modes, the media come from the URLs pinned in `config/versions.json` and are verified with SHA-256 before use. The guest's remaining evaluation days are reported in `health.json`; the host extends the evaluation by itself with `slmgr.vbs /rearm` when 30 or fewer days are left ([step runner](../bootstrap/README.md#step-runner)), and rebuilding the guest starts a new evaluation period. In `JumpstartImage` mode, the image is verified against the blob's own Content-MD5 and length, and its Windows Server 2022 Standard isn't an evaluation.
