# Official sources

The official sources for the APIs, commands, and settings this repo relies on, grouped by topic; every check result also carries the exact page it relies on, in its `docUrl`. They were checked from 2026-10-19 to 2026-11-19, and a line gives the date where a page's label or content matters. Previews change, so re-read a page before you build on it. The approved plan's original source list (plan §8) is included.
