Without a body, Windows PowerShell 5.1 sends a POST as `application/x-www-form-urlencoded`, which the PostgreSQL resource provider refuses (HTTP 415 `UnsupportedMediaType`; the VMs' provider accepts it), so T4's start failed, and Stop now, the auto-stop, and the daily T4 safety stop would have left a running T4 running. A POST without a body now sends an empty JSON object as `application/json`. And when T4's start fails, or T4 is still stopping, the run skips T4 at once instead of waiting 15 minutes for it, which had delayed the other targets' activity until just before the run's auto-stop.

- The LSA secret Azure's provisioning leaves (live, 2026-11-06; user-directed): every deploy reported `T2.ARC.ONBOARDING` as a **Warning** that "Windows automatic sign-in was left armed on archost01". The sweep now counts it apart, its cleanup deletes only that secret, and the result keeps its **Pass** with a note.
